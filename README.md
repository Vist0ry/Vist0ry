## Проекты

<table>
<tr>
<td width="50%" valign="top">

### 🌐 [SkyBioML Portal](https://skybioml.space)

**Веб-штаб эскадрильи**

- HQ — досье командира, состав, панель управления
- Синхронизация телеметрии из игры
- Powerplay, Road 2 Riches, Community Goals
- Мессенджер и система ролей

</td>
<td width="50%" valign="top">

### 📡 [SkyLink](https://github.com/Vist0ry/SkyLink)

**Windows-агент для портала**

- Передача данных из журнала Elite Dangerous
- **Messages** — мессенджер с полной синхронизацией: сайт · Discord · приложение

[Скачать SkyLink.exe](https://github.com/Vist0ry/SkyLink/releases/latest/download/SkyLink.exe)

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 🤖 SkyBot

**Discord-инфраструктура эскадрильи**

- Slash-команды для участников и staff
- Модерация: ban, kick, очистка каналов, фильтр слов, audit-логи
- AI-ассистент в выделенном канале и игровые авто-ответы
- Репутация участников
- Настройка каналов, база знаний и панель статистики для staff

</td>
<td width="50%" valign="top">

### 🛠 [Shipyard](https://builds.skybioml.space)

**Конструктор аутфиттинга**

- Самостоятельный калькулятор сборок кораблей
- Расчёт массы, энергии, брони и вооружения
- Импорт по ссылкам **Coriolis**, **EDSY** и **SLEF**
- Экспорт сборок и открытие с портала

</td>
</tr>
</table>
